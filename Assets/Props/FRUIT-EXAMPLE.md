# 果实与向导交付示例

打开 `Assets/Scenes/PropsDemo.unity` 运行。出生点下方已经放置“果实”，右侧的“向导”使用分支对话。

1. 靠近果实按 **E** 拾取，按 **I** 查看背包中的“果实 × 1”。果实不阻挡角色，拾取后从地图隐藏。
2. 靠近向导按 **E** 交谈；E / Space 逐句继续。
3. 询问结束后按 **1** 或点“交给果实”，按 **2** 或点“不给”。**Esc** 取消。

| 情况 | 向导对白与背包结果 |
| --- | --- |
| 没有果实 | 提示去寻找附近的果实；不显示交付选项。 |
| 持有果实 | 先询问是否愿意交给，然后等待明确选择。 |
| 选择交给 | 显示感谢与新的对白；完整读完才扣除 1 个果实，设置 `guide_fruit_given`。 |
| 选择不给 | 显示“果实先留给你自己”的对白；果实保留，可稍后再交付。 |
| 中途取消 | 不消耗果实、不设置完成标记、不触发交付完成事件。 |
| 已经交付 | 再次交谈显示恢复精神后的对白，不会重复消耗或触发交付完成事件。 |

## 在两个编辑器中修改

- **Tools → 道具编辑器**：“果实”和“向导”都在默认道具库中。果实是任务物品，背包键为 `fruit`，拾取数量为 1，有独立像素贴图。
- **Tools → 像素地图编辑器 → 交互道具**：同样的两份资产可选、可放置，右侧显示同一个自定义属性编辑器。
- 选择向导，在“物品交付与分支对话”中修改物品键、数量、完成标记、按钮文字，以及“询问／交给／不给／没有物品／已经交付”五组对白。顶部摘要直接显示不同状态的对白。
- 选择果实，可修改外观、实体属性、拾取范围、背包键和数量。“保存资产”会保存配置，场景中的放置位置需要保存场景。

这些配置存储在 `Assets/Props/Library/Definitions/Fruit.asset` 和 `Guide.asset`；外观在 `Assets/Props/Art/Fruit.png`。不需要为每段对白修改代码。完成标记非空时只交付一次；留空可重复交付。普通前置物品条件会阻止整个交互，不适合“没有物品仍然交谈”的用法，交付条件应填写在分支区域中。

背包、果实拾取状态和交付标记沿用 `PropGameState.CaptureJson()` / `RestoreJson()`；接口说明见 [道具系统说明](README.md)。

## 验证

**Tools → 道具系统 → 验证果实交付流程** 使用实际的两份资产验证分支对白、背包、交付、取消、重复交付和存档恢复。报告为 `Validation/fruit-quest-results.json`。原道具回归测试仍在 **Tools → 道具系统 → 运行验证**。

**Tools → 道具系统 → 创建果实与向导交付示例** 可补充缺失资产与场景实例；已配置的分支和已存在实例会保留。
