# 首领难度验收 v0.5

日期：2026-10-06。Unity 2022.3.12f1。数值版本：`v0.5-counterplay`。

## 结论

官鬼 8 点无法再通过单纯连击或回蓝药堆伤害击败首领。在新数值的 88,000 场模拟中，所有官鬼 8 点策略均 0 胜，所有纯攻击策略均 0 胜，首领没有两回合通关。攻防续航、控制续航、防御续航仍可无物品通关。

## 问题复现

旧测试只模拟默认加点与无物品打法，验收条件只有不超时。新增五亲构筑、物品包、连续重击与普通攻击压力测试后，复现了：

- 官鬼 8 点、无物品：纯输出 300 / 300 胜，中位数 4 回合。
- 官鬼 8 点、初始包：纯输出 300 / 300 胜，中位数 3 回合。
- 官鬼 8 点、双回蓝压力包：纯输出 300 / 300 胜，全部 2 回合。

基线文件：`Validation/battle-balance-baseline-v0.4.json`。旧规则中，玩家同轮多次攻击、有限回蓝药和固定 ×1.8 属性倍率的组合，足以在首领形成持续压力前击杀。

## 修改

死海残响 HP 从 270 改为 400，增加 60% 潮棘反震。攻击造成实际 HP 伤害后，反震该伤害的 60%，再按主角当前减伤、破绽、护盾结算。敌盾吸收部分及溢出伤害不反震；伤害物品、致命攻击同样触发。双方同时倒下判失败。

这项敌人能力不读取加点类别，不直接禁止某种构筑。官鬼倍率与加权解锁规则保持不变；防御、护盾、治疗和控制让角色有能力持续输出。普通敌人的反震比例为 0。既有 version 1 / 2 会话不会获得反震机制。

首领状态栏、意图悬浮框解释潮棘；技能和伤害物品的悬浮框预览当前反震 HP 损失。战斗日志记录实际伤害、反震比例、护盾抵消、主角损失与剩余 HP。

## 模拟方法与结果

每组使用相同的 1,000 个种子，范围 31001～32000，只根据玩家可见信息行动。首领测试六种构筑、四种策略和三种物品包，共 72,000 场；四个普通遭遇补测 16,000 场。策略为纯攻击、固定防御后攻击、应对意图与反震、普通攻击连点。

初始包为医疗包 ×2、凝神剂 ×1、驱秽符 ×1、散灵符 ×1；双回蓝压力包额外增加一瓶凝神剂。无物品组的背包为空。

| 构筑 | 点数 | 无物品胜率 | 初始包胜率 | 初始包中位回合 |
|---|---|---:|---:|---:|
| 均衡 | 2 / 2 / 2 / 1 / 1 | 47.7% | 90.8% | 13 |
| 输出配续航 | 1 / 0 / 6 / 1 / 0 | 90.3% | 100% | 11 |
| 攻防续航 | 2 / 0 / 4 / 2 / 0 | 100% | 100% | 11 |

纯官鬼在双回蓝包、固定防御和应对策略中也为 0 胜。全部模拟无超时。

## 新验收门槛

- 首领两回合胜利数必须为 0。
- 官鬼 8 点在全部受测策略和物品包中胜利数必须为 0。
- 首领纯攻击及普通攻击连点的胜利数必须为 0。
- 指定攻防续航、控制续航、防御续航的无物品胜率至少 80%。
- 默认均衡构筑带初始包的胜率至少 80%。
- 全部模拟无超时。

战斗与实际 UI 回归 210 项、Day1 剧情与教学战斗回归 210 项全部通过。功能检查包括反震预览、盾与减伤、敌盾吸收、削弱 / 易伤 / 破绽、物品、致命攻击、同时死亡、存读档、旧会话和实际 UI。独立边界测试放宽到无限 MP 和最优攻击序列，在不防御、不使用治疗技能的条件下，反震成本最低为 222 HP，高于 100 HP 加两份医疗包的 170 HP 总预算。
