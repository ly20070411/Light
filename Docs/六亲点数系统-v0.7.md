# 六亲点数系统 v0.7（2026-10-08）

本次完成角色基础加点、成长道具配置、六爻检定与顺序点数计算。新的战斗回合流程尚未定义，因此这里只计算六项基础行动的数值与附加效果清单，不执行伤害、护盾、状态或行动点消耗。

## 角色创建

新游戏先进入六亲加点页面：父母、子孙、官鬼、妻财、兄弟、我，各默认 1 点；另有 8 点可任意分配，基础点数合计 14。单项最多 9 点，不能减到 1 点以下。“我”独立参与分配。

确认时保存的是基础点数，不含成长或检定，不再显示旧技能倍率。设置中的重新加点只修改基础点数，保留道具、背包和剧情进度；已开始的检定继续使用其冻结的原数据。

旧存档仍可读取。五亲旧规则的角色在继续游戏时先重新分配六项基础点数；取消不改原存档，确认后保留位置、剧情、背包、侵染、历史检定及已有战斗存档。

## 点数计算

1. **基础点数**：创建角色时确认的对应属性值。
2. **成长点数**：配置到该属性的道具数量，每件固定 +1。
3. **局外点数** = 基础点数 + 成长点数。
4. **检定点数**：现有铜币投掷 → 六爻排盘评分；五亲同类取最高，缺类为 0，“我”取世爻得分。保留正负数。
5. **当前点数[0]** = 局外点数 + 检定点数。
6. 从第一个配置道具开始，按顺序判断条件、执行点数变动。一个道具完成后得到当前点数[1]，下一个得到当前点数[2]，以此类推。没有触发条件的道具也推进一次迭代。
7. 最后一次迭代结果即**最终点数 x**。

`当前点数*n` 表示第 n 次迭代，绝不视为乘 n。点数补正通过道具规则逐项执行，不能预先合并成一个加值，否则会丢失顺序差异。

每条道具规则分别指定条件左值、右值、操作与操作数。可明确引用常量、基础、成长、局外、检定或当前点数；支持加法、赋值、整数乘法、取较小/较大值，以及大小、相等和不等条件。同一道具里的多条规则也按顺序执行。

计算保持有符号整数；不擅自把负检定或负最终值截成 0。溢出会明确拒绝计算。子孙的 1.25 系数和百分比行动保留小数；其在实际战斗中的取整、上下限、持续时间和叠加规则留待战斗流程确定。

## 六项基础行动数值

| 属性 | 计算结果 |
|---|---|
| 官鬼 | 造成 x 点伤害 |
| 父母 | 获得 x 点护盾 |
| 妻财 | 赋予 x × 12.5% 易伤 |
| 子孙 | 目标敌人攻击最终点数减少 x × 1.25 |
| 兄弟 | 增加 x × 10% 伤害 |
| 我 | 获得 x 点行动点 |

百分比在接口内保存为比例，如 x=3 的易伤为 0.375，界面显示 37.5%。子孙 x=3 对应削减 3.75 点。此阶段只输出数值，不对旧战斗对象施加这些效果。

## 道具配置与获得

游戏中按 **P**，或点击左侧“六亲成长道具”，进入配置与试算面板。选择属性后，可从背包配置成长道具、卸下返还、上下调整执行顺序。迁移到另一个属性可先卸下再配置；代码接口也支持直接移动。

配置会从普通背包占用一份实物；配置中的物品不会同时被重复装备或作为消耗品使用。卸下仅返还这一份。道具的 +1 成长只计算在配置的属性上，未配置时不提供成长点数；调整顺序不改变成长总量。

配置页面显示基础、成长、局外点数，支持使用真实六爻排盘试算，并展示每件道具的前后值和最终行动数值。试算可重复，不会消耗资源或执行战斗行动，也不会改写剧情检定结果。配置页面打开时暂停角色移动和世界交互。

道具库：`Assets/Resources/Checks/PointItemCatalog.asset`。

在 Project 中选择 `Create → Emerge → 点数系统 → 成长道具` 创建资产，再加入道具库。`PointItemData` 中填写唯一物品键、名称、说明、点数规则及行动附加效果。现有世界道具 `PropDefinition` 可设置 `pointItem` 引用；拾取自动使用成长道具的物品键。剧情奖励也可通过既有背包奖励接口发放同一个键。

预置示例：

| 道具 | 物品键 | 成长与补正 |
|---|---|---|
| 剑 | `points.sword` | 成长 +1；当前点数 < 局外点数时，设置为局外点数 |
| 符咒 | `points.talisman` | 成长 +1；当前点数 +2 |
| 平安结（占位） | `points.knot` | 成长 +1，无额外补正 |

官鬼基础 5、配置剑和符咒、检定 -1：局外为 7，当前[0] 为 6。剑 → 符咒得到 **6 → 7 → 9**；符咒 → 剑得到 **6 → 8 → 8**。

行动附加效果会生成包含来源道具、效果键和数值的清单，供后续战斗流程执行。被动和终结技没有明确规则，本次不新增其执行机制。

## 存档与兼容

角色存档保存配置道具的实例 ID、物品键、归属属性及顺序。检定开始时额外冻结道具定义、基础属性和顺序；恢复时重算最终值，并核验每一步已保存结果。重复实例、非法属性、损坏的中间过程和溢出均会被拒绝。

属性规则版本为 3。版本 2 的历史检定仍保留原先“我归入父母”的行为，历史结果不重算。新规则的“我”独立计算。

旧 MP 战斗暂时继续使用独立的五亲 8 点默认配置。新的 14 点基础值不会进入旧版每点 +10% 的公式。旧战斗存档保持原规则；待战斗流程明确后，将新数值计算接口接入实际战斗。
