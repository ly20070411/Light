# Day1 可玩占位版

场景：`Assets/Scenes/Day1ResearchStation.unity`。

在 Unity 选择 **Tools → 剧情 → Day1 → 打开可玩场景**，按 Play，再选主菜单的“新游戏”。角色移动沿用 PixelRoom：WASD / 方向键，Shift 加速，E 交互，E / Space 继续，数字键选择，I 背包，M 区域图。右上角“制作备注”可查看占位说明。结束当天后停留在第一日场景，第二日尚未制作。

## 已接入的流程

1. 入站自动进行三题认知校准；选择需复核的答案时给出提示，重新确认。完成后身份认证卡收入背包，核验门开放。
2. 六名队员在总控室集合。规则终端完整宣读后队员回到各自作业位置。
3. 环境监测台保存数据档案并发送食堂物资通知。
4. 领取生活物资后，出现一次带雪花噪点的无名影子。主角将它归因于灯光接触不良，之后开放自由探索。
5. 与六名队员接取并回报任务：林溪的终端检查、植物样本、外围战斗、装备维修、码头工具与零件，均使用现有系统；水文学家的采水任务由杨应隆在蚀海侧入口劝阻，回报后保留至第二日。
6. 五项可执行作业完成，并回报明日采水安排后，规则终端允许选择结束第一日。取消、稍后与继续探索均保留当前进度。

四项采集 / 维修检定使用真实六次投币和排盘。失败仍获得基础任务结果，成功另获校验记录、完整植物样本或备用零件；这些奖励目前只作背包物品，尚未绑定后续增益效果。外围战斗使用独立教学遭遇及现有六爻战斗 UI，胜利后向杨应隆回报。

## 地图与角色

地图完全沿用 PixelRoom 的正视二维 Camera、SpriteRenderer 和 Physics2D，没有倾斜相机。八个区域：认知缓冲间、总控室、生活区餐厨走廊、机房、化学分析室、仓储区、站外草地 / 边界、码头。其余未在第一日细纲中使用的房间暂未搭建。

地板和墙由默认 Stone / Brick / Grass / Water 方块派生，保留 MapBlockInstance 与 PixelMapRoot，可用原地图编辑器修改。默认定义未被修改。地图库：`Assets/Day1/Maps/Day1MapLibrary.asset`；交互库：`Assets/Day1/Config/Day1PropLibrary.asset`。

玩家和六名队员引用已创建的角色占位资产。四位未命名队员使用职业称呼。谭礿仅作为无名影子的幕后外观引用，不显示姓名或头像。角色集合位置与作业位置分开记录，读档或战斗撤退后按规则宣读状态重新同步。

### 总控室美术与遮挡（2026-10-07）

Day1 总控室已绑定 `Assets/美术资产/总控室（初稿）.png`。保持原图 5:6 比例、5000×6000 分辨率，未改写原始图片；场景材质去除白底，外围使用暗色虚化过渡，室内保持清晰。缓冲间、机房、生活区、化学室和仓储区通过五条有独立碰撞的过渡走廊连接。相邻占位区域在 Day1 内移位，为原图比例留出空间。规则、环境监测、诊断交互点绑定图中设备；保留交互 ID、剧情配置和存档系统。

下方斜墙和前墙采用与原图接近的灰蓝墙面、浅色压顶及细轮廓线。`Day1OcclusionFade` 同时检查玩家的脚点和 Sprite 的实际遮挡范围；遮挡时约 0.18 秒降至 28% 不透明度，围绕玩家轮廓柔和过渡，离开后延迟 0.12 秒、约 0.32 秒恢复。只有遮挡玩家的局部淡出，墙体碰撞一直有效。中央设备也有独立前景与脚部碰撞，遮挡时保留 38% 不透明度。

可在 **Tools → 剧情 → Day1 → 应用总控室美术与遮挡** 重建本场景的美术层；重复应用不会再次移动房间。新增墙体、材质和网格保存在 `Assets/美术资产/总控室场景`，运行参数在 Day1 层级的 `A02 总控室 · 正式美术与遮挡` 中调整。**验证总控室碰撞与淡出** 使用隔离的真实 Play 会话，检查渐变、恢复、碰撞及五条走廊的双向通行，不写玩家存档。结果与截图为 `Validation/day1-controlroom-*`。原有完整 Day1 流程验证仍可运行。

## 进度与验证

长期进度沿用玩家 PropGameState 的旗标与背包，由原菜单存档系统保存。对话取消不提交主线或任务交付；检定本身沿用原系统的固定起卦与结算，不重复发奖。物资领取与影子看完分开存储，中途读档会安全重播未完成影子。蚀海侧第一日始终不开放，不因战斗胜利而解除。

验证入口：**Tools → 剧情 → Day1 → 运行完整流程验证**。它使用独立临时存档，走真实菜单、对话选项、起卦动画与战斗按钮，并检查七个门洞的实际物理通行。结果保存为 `Validation/day1-results.json`；地图预览由同菜单的“导出地图预览”生成。
