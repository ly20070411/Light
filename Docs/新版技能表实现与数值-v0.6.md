# 新版技能表实现与数值 v0.6

日期：2026-10-06。Unity：2022.3.12f1。配置版本：`v0.6-skill-table`。战斗会话版本：4。

本版按照用户提供的《技能表.docx》实现30条技能身份，保留3个常驻指令，总计33条定义：24个五亲主动技能、4个独立终结技能、2个独立被动天赋，以及普攻、固守结界、清心。本文记录实际回合规则与已完成的70,000场无物品验收结果。

当前候选新增基础守御40%和归息即时回复30，安装器源码已更新；这两项仍待统一编译、安装及最终模拟决定。其余四项控制费用已安装：山障12MP、日辰8MP、变爻10MP、引灾10MP。

## 五亲、加点、候选与强化

总点数必须为非负整数且合计8点。普通技能及常驻指令按所属五亲使用 `1 + 0.1 × 点数` 的基础倍率。0点类别不进入普通高级候选，但其常驻指令仍可使用。终结技能和独立被动的倍率固定为1。

| 五亲 | 表内编号 | 技能数 | 本表定位 |
|---|---|---:|---|
| 妻财 | 1～5 | 5 | 直接输出、破防、窃取与攻击规避 |
| 官鬼 | 6～12 | 7 | 雷火标记、持续伤害、控制与诅咒 |
| 子孙 | 13～17 | 5 | 风刃、驱散、恢复、吉凶与条件输出 |
| 父母 | 18～22 | 5 | 护盾、分身、增益领域与反伤 |
| 兄弟 | 23～24 | 2 | 变爻爆发与引灾 |

定卦只生成本轮候选，不参与技能伤害倍率和吉凶结果。普通候选先按类别加权，再在该类别剩余技能内均匀抽取，并移除已抽技能。类别的整数权重为 `该类点数 × (4 + 卦中该类爻数)`。技能池扩大后，单条技能的类内概率按实际有效数量重新计算；不能沿用旧技能池的单条概率。

终结候选采用独立随机流，均匀选择仍有本场次数的终结技能，不读取五亲点数，也不受普通抽签消耗随机数的数量影响。被动不进入候选池，自动按事件触发。抽到候选不会扣MP、消耗次数或消耗强化。

只有原表明确写有强化描述的16个技能可强化：1、2、3、6、7、8、9、10、11、13、16、18、19、20、21、23。所属五亲达到3点且本轮抽中时，该技能本场首次成功施放自动强化，费用与普通版相同；此后恢复普通版。每个技能各有一次强化记录，跨轮和读档不会恢复。MP不足、目标非法等被拒绝的操作不消耗强化、次数或随机流。总8点最多使两类达到3点阈值。

同一轮仍可重复使用已抽中的技能，直到MP或本场次数耗尽。“最多3个候选”限制可选技能身份，不限制本轮总施放次数。普通版不会用较弱效果延长已有强化效果；较强状态自然到期，护盾也不会通过较小数值续期较大的旧护盾。

## 秒制转回合与结算顺序

原表的秒是原型效果时长。本版以2秒约对应1轮、向上取整作为初始转译参考；每秒、每0.5秒、触碰等事件改为明确的回合事件，不能按现实等待时间持续生成输出。技能表内的次数、伤害预算和触发频率同时采用已明确的回合定义。

| 原效果 | 回合实现 |
|---|---|
| 乾元8秒逐层增伤 | 4轮，普通初始8%，后续每轮＋8%至20%；强化即刻满层 |
| 金泽破防6秒 / 窃取5秒 | 各3轮 |
| 雷动震标7秒 | 4轮，强化引爆明确消耗标记 |
| 炎光灼烧4秒 | 2轮，每轮5／强化8 |
| 山障3.5秒、禁锢1.2秒 | 输出降低2轮；强化控制一次，不按几何触碰重复伤害 |
| 引晦标记10秒 | 5轮，每轮8 |
| 日辰输出降低5秒 | 3轮 |
| 养蛊领域6秒、每1.5秒生成虫 | 3轮，每轮1虫；强化2虫，分成两次随机攻击 |
| 风刃盘旋3秒、每0.5秒切割 | 2轮，每敌一个实例，每轮一次6 |
| 坤领域6秒及每秒回血 | 3轮盾、后续2轮各回复4 |
| 分身持续4秒 | 用户另行明确为4轮、每轮一次随机攻击17 |
| 换位0.6秒闪避 | 调试转译为本轮20%减伤，没有整轮免疫 |
| 月建增伤16秒 | 8轮 |
| 三爻领域12秒、每2秒事件 | 6轮，每轮一事件 |
| 变爻禁回MP3秒 | 2轮状态；持续期间阻止相关回MP节点 |
| 终结增益8秒、爻定增益7秒 | 各4轮 |

玩家结束本轮时，先结算分身、蛊虫、盘旋风刃，再结算敌方灼烧／引晦，之后结算领域事件。召唤与持续效果的第一次数值结算包含施放当轮；后续敌人按顺序行动。进入下一轮时推进状态期限、清理到期效果、恢复MP与持续回血，再生成新定卦候选。

召唤与持续伤害在创建时保存基础属性倍率，结算时读取当前增伤、削弱等状态，不暴击。分身、蛊虫、盘旋风刃是独立召唤实例；标记和同类增减益使用明确的刷新规则，不按每次点击无限相加。持续回血使用既有单一通道，重复施放不叠成多条独立回血事件。护盾按数值替换和持续期限处理，不直接相加。

三爻同动每轮等概率抽取六种事件之一：增伤15%、减伤15%、即时回复10生命、输出降低15%、受伤＋15%、灼伤4／轮。除即时治疗外，效果持续2轮。普通版所有事件给予主角；强化版前3项给予主角，后3项给予随机活敌。没有活敌时不向主角回退发放强化负面。

## 反震、反弹、反噬与随机状态

首领以实际扣除的HP作为反震基数，排除敌盾吸收部分和超杀部分。基本反震比例30%，受首领当前输出削弱影响，随后按主角当前减伤、受伤提高和护盾结算。直接伤害、召唤、持续伤害、伤害物品与致命命中都可能触发首领反震，分身造成的反震由主角承担。

玄甲和被动29的反射伤害不会再次触发首领反震；首领反震也不会被当作敌方直接攻击触发受击回MP和再次反弹。自身反噬直接扣HP，无视护盾，不触发被动或反伤；反射和反噬不暴击。双方同时倒下判失败。

六爻断命、爻定吉凶、暴击、被动概率和召唤随机目标使用可保存的执行随机流。UI预览不推进随机数；读档保留已使用的强化、次数、随机序号、状态、领域和召唤。施放被拒绝时这些信息不变。暴击加成充能影响之后的单体直接伤害技能，当前动作只产生下一次充能。

敌方防御为减伤比例。破防12%表示将原15%防御的有效部分乘以88%，不是直接扣除12个百分点。多项破防／无视防御合并后取有效范围上限。百分比增益与伤害倍率的实际组合、取整及反震损失均记录在战斗逻辑日志中。
