# 点数战斗与局外道具 v0.8

本版接入六项基础点数、成长道具、真实六爻检定、单个精神锚和行动点战斗。终结技继续后置。旧 MP 战斗由原引擎读取；新建或完成六亲加点升级的角色进入新规则。

## 每回合

1. 回合开始结算流蚀：直接扣除等于层数的生命，然后减少一层；护盾不吸收流蚀。
2. 显示敌人的固定行为预告，投掷六次三枚铜币，用现有排盘规则得到六项有正负的检定点数。
3. 若携带鹿见深精神锚，正检定翻倍，检定小于等于 0 的对应行动禁用。对“我”也适用；固定 3 AP 始终获得。
4. 六项分别计算基础 + 成长 + 有效检定，再依配置顺序执行道具。保留负中间值，仅在整条道具链结束时把最终值限制为不小于 0。
5. 一次性获得 `上回合保留 AP + 3 + 我最终点数`；“我”不可手动重复使用。其装备附加效果在此执行一次。
6. 玩家行动每次花费 2 AP，可重复行动；行动点不足也不会自动结束回合。
7. 玩家主动结束，最多保留 1 AP。存活敌人逐个执行预告行为。
8. 敌方回合结束，玩家施加的易伤、增伤、攻击点数削减清零。进入下一轮。

## 五种行动

| 六亲 | 基础效果 |
| --- | --- |
| 妻财 | 对目标造成 x 基础伤害 |
| 官鬼 | 获得 x 护盾 |
| 子孙 | 目标易伤增加 x × 12.5% |
| 兄弟 | 目标每段攻击点数减少 x × 1.25 |
| 父母 | 自身增伤增加 x × 10% |

默认单体，官鬼和父母作用于自己。重复施加比例/削减相加。

伤害为 `max(0, 基础伤害 × (1 + 增伤) × (1 + 目标易伤) − 攻击方受到的削弱)`，然后先扣护盾再扣生命。数值保留小数，UI 显示两位。敌方多段攻击每段单独受到攻击削减；削减后最低为 0。护盾在持有者下一次行动阶段开始前清除。敌方施加的易伤/削弱持续到下一次敌方回合结束，流蚀独立递减。

## 精神锚

- 林溪：兄弟行动额外赋予 `floor(x × 0.5)` 层流蚀，重复施加层数相加；兄弟每轮最多两次，下一轮重置。
- 鹿见深：以原始检定点数正负判定，正数翻倍再进入道具链；零和负数禁用对应行动。道具无法绕过禁用。
- 同时仅一个生效，战斗开始冻结选择，战斗期间不能更换。
- 剧情成功完成时调用 `CheckActorState.CreateMentalAnchor`，或配置 `PropDefinition.createdMentalAnchorId`。也可通过 `PointStoryRewards` 连接剧情事件。已实现的角色 ID 为 `lin-xi`、`hydrologist`；其余人物的被动效果尚未定义，不自动编造。

## 道具与唐晦

- 成长点数始终为每件配置道具 +1；物品的效果和成长点数分开保存。
- 标记 `PointItemDefinition.randomizeOnAcquire` 的故事道具获得时生成独立词条和实例 ID。装备、卸下、读档保留词条与实例。
- 初始效果池提供稳固、聚焦、护佑、生息、侵蚀、追击占位效果；道具可同时携带顺序点数规则和行动附加效果。
- 已绑定 Day1 的剧情奖励、拾取道具和故事草稿库中的物品，包括身份认证卡、环境数据档案、检修工具、生活物资、现实稳定锚、铜钱及水样。消耗未装备的剧情物品会同时移除其成长道具实例；已装备物品仍占用一份实体，不可重复消耗。
- 在主角卧室或仓储区可调整道具归属、执行顺序和精神锚。其他位置允许查看及试算。
- Day1 仓储区沿用现有地图区域判断；新的卧室/仓储场景添加 `PointConfigurationZone`。唐晦附近才能改装；测试场景使用 `PointRefitStation` 占位。
- 唐晦每次提供三个不同效果，选一个替换原有完整词条，保留道具身份与 +1 成长；取消或重开不重抽。
- 每个剧情日两次改装、一次刷新；次数与待选效果存档。通过剧情事件调用 `BeginStoryDay(day)` 进入新日期，现实跨日和重复提交同一天不重置额度。
- 兼容治疗、净化和群伤消耗品，每次 2 AP，采用独立 `pointPower`。回蓝道具不适用新的 AP 系统。难度验证不使用消耗品。

## 敌人、存档与测试

`PointBattleRules.asset` 配置主角生命、敌人生命与循环行动列表。预告在玩家行动前确定；卦象不影响敌方行为或基础数值。玩家的削弱会实时改变预告伤害。新引擎支持任意数量敌人，UI 横向滚动选择目标。

`PointBattleDemo.unity` 提供单敌、双敌和四敌三个遭遇，装备/精神锚/改装均可在场景里测试。Unity 菜单：`Tools > 点数战斗 > 打开测试场景`。

原有 `BattleSingleDemo`、`BattleDualDemo`、`BattleTripleDemo`、`BattleDefenseDemo`、`BattleBossDemo` 同样接入新系统，入口与终端交互保持一致。五个场景都可按 P 配置装备、精神锚与改装。其 E01/E02/E03/B01 敌人使用独立点数配置：海蚀影 24 HP、护壳体 28 HP、扰识体 20 HP、死海残响 60 HP；旧版 MP 数值仍供旧存档使用。

两套规则统一使用原 `BattleView` uGUI。主角左、敌人右、四页操作面板、相邻状态说明、铜币揭卦、动作与结果框沿用原布局和素材；主角蓝条改为 AP，敌人蓝条为护盾。新规则的技能按钮显示五种基础行动，悬停可见正负检定、装备顺序计算链、最终值、附加效果和禁用原因。

战斗快照保存铜币进度、当轮点数链、AP、效果、敌人预告和战前世界。读档不中断或重掷当轮检定，不重复获得 AP/胜利奖励。逃跑恢复战前剧情、坐标、背包、词条和改装次数。每次胜利记录回合数与最佳回合数，供成就使用。

验证入口：`Tools > 点数战斗 > 运行功能与存读档验证`。报告在 `Validation/point-battle-results.json`；旧点数链和旧技能表有独立回归报告。

验证包含五个原场景的新游戏入口、共享 uGUI、按键选敌与高亮、技能计算链及相邻状态说明、四页切换、连续行动、物品、结束回合、意图、逃跑，以及单敌场景的实际存读档。界面截图保存在 `Validation/point-battle-original-*-preview.png`。

原剧情检定会话保留 v0.7 的冻结计算记录以兼容已有存档；新版行动归属、最终点数下限及精神锚规则应用于 v0.8 战斗。
